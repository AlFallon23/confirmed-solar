# Confirmed Solar website

Static site, no build step. Open `index.html` or serve the folder.

## Put it live
1. Buy the domain (check confirmedsolar.com at a registrar first; it showed no DNS records, which is not proof it is free).
2. Cloudflare Pages or Netlify: create a project and drag this folder in. Both are free for a site this size.
3. Point the domain at it.

## Edit
- Contact details and prices: `$1` / `$5` appear in `pricing.html`, `index.html`, `calc.js`.
- Counts are deliberately not shown. County sizes on `coverage.html` are bands (Thousands, Hundreds, Under 100).
- Legal pages are plain-language templates, not legal advice. Have them reviewed.
