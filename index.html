What this is

There is no public list of which houses have solar. This is one. It is a prospecting list of homes, not inbound leads: nobody on it has asked for a quote. You get the address, and for most of them the exact install date and system size, so you can decide who is worth a call or a visit before you send anyone out.

Who uses it

  • Roofers doing panel removal and reinstall
  • Solar repair and maintenance
  • Panel cleaning
  • Critter guard and bird proofing
  • Battery storage retrofits
  • Inverter replacement

What comes with each address

Location, ZIP and county on every record. Exact install month and year and exact system size in kilowatts on most. Array size ranking, roof complexity and panel type where available.
